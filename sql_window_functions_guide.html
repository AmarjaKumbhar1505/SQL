The core idea — what is a window?
Normal GROUP BY collapses rows into one. A window function looks at a "window" of related rows — but keeps every row. You get the calculation AND the original row together.
ROW_NUMBER()   OVER  ( PARTITION BY dept   ORDER BY salary DESC )
Function
OVER — opens the window
PARTITION BY — group within window
ORDER BY — sort within window
ROW_NUMBER()
Unique number per row — no ties ever
RANK()
Tied rows get same rank, next skipped
DENSE_RANK()
Tied rows same rank, no gap after
NTILE(n)
Splits rows into n equal buckets
SUM() OVER()
Running total or group total
AVG() OVER()
Moving or group average
COUNT() OVER()
Count per partition on every row
MAX() OVER()
Max value from partition on every row
LAG(col, n)
Value from n rows before current
LEAD(col, n)
Value from n rows after current
FIRST_VALUE()
First value in the window frame
LAST_VALUE()
Last value in the window frame
